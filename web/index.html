Browser Requirements

  • Web Bluetooth: Chrome, Edge, or Opera on desktop / Android. On macOS, Bluetooth must be enabled.
  • WebUSB: Chrome, Edge, or Opera on desktop / Android. On Linux you may need udev rules for VID 0x0716. On Windows you may need a WinUSB driver via Zadig.
  • The page must be served over HTTPS or localhost. GitHub Pages satisfies this automatically.
  • No data is sent to a server - all communication stays inside your browser.
